# 原生会话 AI 圆桌

目标版本：Windows Harness 0.2.0-rc.2，安装包 commit 04f392c9ddd144fa426da2045178797da6db6c11。

## 范围

这是新插件，开发与验证均位于本目录。旧插件、旧讨论和宿主安装文件不变；不迁移旧数据。
一场圆桌对应一个普通原生 Session。用户从原生工作区列表选择工作区；Session 创建和打开、权限、附件、命令及附加操作使用原生路径。
插件不实现第二套工具循环或消息存储，也不启动参与者子 Agent。

## 原生边界

- 本体新聊天及工作区选择负责创建和打开 Session。首次发送前，插件在当前 Session 的原生维护边界绑定圆桌，不创建第二个 Session 或空初始化 turn。
- 启用开关、模型配置均先保存为客户端草稿；重新点击本体新聊天时重置草稿。首次发送被拒绝时可撤销未提交绑定，恢复之前的会话模型选择；有实际用户消息的圆桌不允许撤销绑定。
- 原生输入框、上传、权限选择、命令菜单和右侧工作区面板保持原样。圆桌开关、任意成员组合及配置窗口通过附加 slot 提供；无成员勾选时通过原生 composer blocks 阻止发送并保留草稿。
- 原生 conversation.sendSession 前只同步圆桌绑定和附件能力检查，之后继续原生的附件序列化、乐观提交、权限和输入失败恢复。接入方法在卸载时恢复。
- scoped system-prompt/assemble 与 agent/request 固定本次成员的路由；不调用会修改全局默认的 selectModel。
- 每名成员占一个原生 turn，可以包含任意数量的原生工具 step。
- agent/turn-stopping 在成功完成成员发言后，将下一名成员的内部提示插入原生 next-turn 队首。用户文字只提交一次。
- 原生 turn/end 错误后，等待 whenIdle 并在 runMaintenance 中安排剩余成员，保留用户排队输入。
- 停止当前成员时终止整个圆桌批次，移除本插件产生的剩余提示；用户排队输入沿用本体队列规则。
- 原生 Session 负责正文、思考、工具、流、标题、压缩、导出基础及持久化。插件只保存成员、目标和批次到原生 turn 的索引。
- 本体模型自动标题若返回占位名，复用本体 fallbackSessionTitle 及标准 session/title 事件修复；手动标题优先，不追加 LLM 调用。
- 连接检测复用本体模型配置解析与 BlockAssembler。每次检测使用唯一 ID，取消与新检测隔离；结果只在当前开启的选择窗口内有效，重新勾选始终重测，关闭即取消并清空。正文和思考输出都纳入判断，完整错误原因直接可见。
- 模型选择窗口保留发言顺序编号，思考强度直列按钮；已开始会话的目标按钮无头像、无勾号，位于发送按钮右侧底部。只调整圆桌会话布局，普通会话使用原生布局。
- 输入框和右侧无外框模型区共同分配原生 composer-card-max-width；按钮组上下居中，始终使用 142px 单列。2、3、4 个模型按钮分别高 32、28、22px，间距分别为 4、4、2px，最小输入框高度 98px 时全部可见。运行进度定位在模型区上方，不挤占按钮高度。总宽度由原生 ConversationWidthControls 管理，不提供第二套拖动逻辑。模型回复的原生操作按钮常显；会话列表及当前标题用纯 SVG 圆桌图标区分，标题文本不改写。
- 不向本体写入未知必需事件：安装版的外部事件兼容机制不支持安全保存本插件必需的控制状态，所以成员与批次控制索引独立保存。
- 原生分支的 parentSession 提供成员继承依据，历史索引按原生分支已有轮次裁剪；不重新提交用户消息。
- 色框按控制索引匹配原生回答行，正文不复制、不重新渲染。模型颜色在成员顺序中固定；头像、名称和色框排除 reasoning 节点，思考与工具过程保持本体样式。仅隐藏本插件内部轮转触发提示，原始记录仍留在日志和轨迹中。
- 重启或插件重载将未完成批次标为 interrupted，不自动重发付费请求；已录入原生日志的回答仍可查看。

## 上下文与行为

原生日志保留真实模型来源和工具协议。圆桌动态系统说明明确当前成员、成员名单、用户主持及其他模型发言的归属；内部轮转提示作为可回放的上下文 notice 保存。
2026-10-14 更新的补充段将圆桌讨论参与者写为首要任务身份，Agent 身份解释为执行能力；保留原生提示词与权限、审批、计划等模式约束。补充段借鉴旧插件的持续要求、一次性要求边界、独立判断、完整作答与简短确认、证据归属及结果交付规则。历史发言按实际模型与轮转标记分别归属，轮转本身不增加任务或操作授权。
历史压缩与中断消息采用本体语义，不复制旧插件的字符估算和整轮压缩算法。失败重试以当前共享上下文重新点名该成员，保留原失败记录。
权限采用本体会话权限，所有参与模型共享本场工作区及会话权限。插件不额外授予权限，也不绕过宿主工具执行管线。

## 验证门槛

1. 用安装版真实 AgentLoop 与可控模型验证顺序、工具多 step、失败继续、取消、队列与恢复。
2. 使用原生 slot 验证普通会话不受影响，工作区、权限、附件与附加操作仍来自宿主。
3. 检查输出属于真实请求路由，轮转不会改变全局默认模型。
4. 不把假模型/单元测试当作真实服务商或实际桌面 UI 验收；未验证部分在 README 标明。
