## 完整界面

在本目录 `.test-home-ui` 隔离 Web profile 中加载插件，使用本地验证模型 A/B/C/D。已验证：

- 原生新聊天的圆桌开关默认关闭，复用空会话时能正确重置。
- 2026-10-14 新聊天控件样式更新：34×20px 胶囊滑动开关，点击或空格键切换，圆形滑块左右移动；关闭后原生模型栏恢复。模型选择按钮使用圆桌图标、下拉箭头和 28px 高度的圆角样式，点击仍正常打开原选择窗口。关闭、开启及打开选择窗口已在隔离界面验证。
- 分组多选四模型、第五个模型被阻止、选中后自动测试、检测中取消并重新勾选、直列思考强度和组合记忆。此版已验证：成功或失败模型重新勾选都进入新检测；关闭时取消旧请求，重新打开四个模型均显示“检测中”，不沿用旧结果。
- 连接错误码及具体原因在模型行下直接可见；思考达到输出上限显示“已连接”及明确限制，不再误报不可用。

- 原生回复操作按钮在鼠标移开后仍为 opacity:1；会话列表及当前标题前显示三人圆桌图标。

- 原生工具循环、四模型顺序回答，回复头像、固定颜色框与成员按钮对应；不显示重复的成功状态尾行。
